# Anweisungen für Regionalmitarbeiter

## Purpose
To ensure the correct and uniform completion of the online form.

## Schritte
1. Öffnen Sie die Google-Sheets-Formularvorlage.
2. Füllen Sie nur die verfügbaren Felder aus.
3. Wählen Sie Werte aus den Listen aus.
4. Nicht die Struktur der Tabelle ändern.
5. Daten vor dem Abschicken überprüfen.

## Common Mistakes
- Manuelles Eingeben von Kategorien.
- Pflichtfelder werden übersprungen.
- Verwendung nicht standardmäßiger Namen.
