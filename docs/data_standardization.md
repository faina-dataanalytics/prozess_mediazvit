# Datenstandardisierung

## Zweck
Die Standardisierung ermöglicht eine automatische Datenanalyse und eine einheitliche Berichterstattung.

## Standardisierte Felder
- Television
- Communication channel:
  - Radio
- Fernsehen
  - Radio
  - Online-Medien
  - Drucksachen
  - Kanäle: - Fernsehen - Radio - Online-Medien - Printmedien
- Thematik:
  - Rechtsaufklärung
  - Schutz der Menschenrechte
  - Zugang zu rechtlicher Hilfe
  - Andere
- Typen von Druckerzeugnissen:
  - Plakate
- Broschüren
  - Plakate
  - Broschüren

## Validierungsregeln
- Auswahl von Werten nur aus der Liste.
- Kategorien dürfen nicht manuell bearbeitet werden.
- Automatische Vorschläge und Einschränkungen.
