# Internal Regulation

## Zusammenfassung
Die interne Regelung schreibt die Verwendung der Online-Formulare zur Erfassung der Medienberichterstattung vor.

## Key Points
- Alle Regionen verwenden ausschließlich die genehmigte Form.
- Die Daten werden jeden Monat bis zu einem bestimmten Datum eingereicht.
- Das Senden von Daten in Word-, Excel- oder Textformat ist nicht zulässig.
- Die Verantwortung für die Richtigkeit der Daten liegt beim regionalen Koordinator.
