# Bottleneck Analysis

## Identified Bottlenecks
- verschiedene Datenformate.
- Fehlende Standardisierung.
- Abhängigkeit von einer Person.
- Hohe Fehlerquote.
- Langsamer Prozess der Abstimmung.

## Impact
- Verzögerungen bei der Berichterstattung.
- Niedrige Datenqualität.
- Wysoki poziom obciążenia personelu.
